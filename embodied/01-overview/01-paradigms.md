# 具身智能的三种范式

> 先把技术路线的分歧摆清楚，后面每一册都是在补其中某一条的细节。

## 1. 和 LLM 最本质的五个差异

| | LLM / VLM | 具身（VLA / WAM） |
|---|---|---|
| 输出 | 离散 token，词表有限 | **连续动作**，高维、有物理量纲 |
| 时间 | 用户等得起几百 ms | **实时闭环**，控制频率 10–1000 Hz |
| 错误代价 | 说错话 | **撞坏硬件 / 伤人**，不可回退 |
| 数据 | 互联网规模文本 | **遥操作数据极贵**，几万条已算大 |
| 分布 | 训练≈测试 | **sim2real、跨本体、跨场景**都是分布迁移 |

$$\boxed{\text{LLM 缺的是推理，具身缺的是数据和闭环}}$$

## 2. 三种范式各自赌什么

### 模块化：感知 → 规划 → 控制

每段独立开发、独立测试。可解释、好调试、工业界成熟。

**赌的是**：每个模块都能做到足够准。
**卡在**：误差沿管道累积；感知给不出精确的物体位姿（柔性物、透明物、堆叠）；接触丰富的任务难建模；模块接口把语义信息压扁了。

### 端到端 VLA：观测 → 动作

**赌的是**：数据够多就能学到，就像 LLM 那样。
**卡在**：机器人数据比互联网数据少 6–8 个数量级；泛化到新场景/新本体仍然困难。

### 世界模型 + 规划：先学 dynamics，再在想象中搜索

**赌的是**：学环境动力学比直接学策略**更省数据**，因为动力学是任务无关的、可以用无标注视频学。
**卡在**：模型误差在长 horizon 上放大；规划的实时性。

### 分层：高层出子目标，低层出动作

现在的**实用主流**。VLM 负责语义理解和任务分解，低层用学习策略或传统控制器执行。取两边之长。

## 3. 一张选择图

```text
任务语义复杂、需要理解语言          → 需要 VLM
接触丰富、难以建模                 → 需要学习策略
数据极少                          → 世界模型 / 用无标注视频
要可解释、要安全保证                → 保留模块化的低层
长程多阶段                        → 分层
```

## 4. 几个必须分清的概念

| 概念 | 含义 |
|---|---|
| **embodiment** | 本体（机械臂型号、自由度、末端形态）。cross-embodiment 指跨本体泛化 |
| **open-loop vs closed-loop** | 一次规划走到底 vs 每步重新根据观测决策 |
| **BC（行为克隆）** | 监督学习模仿专家轨迹，就是具身版的 SFT |
| **compounding error** | BC 的经典问题：小误差 → 进入训练分布外状态 → 误差更大，随步数平方级增长 |
| **proprioception** | 本体感知（关节角、末端位姿、gripper 状态） |
| **teleoperation** | 遥操作采数据（VR、主从臂、外骨骼） |

**compounding error 是理解 [action chunking](../05-action/03-chunking-and-realtime.md) 的前提**，也是 [OPD 那套 on-policy 思路](../../notes/06-post-training/distill/03-opd.md) 在具身里同样成立的原因 —— BC 只在专家轨迹上训练，没见过自己犯错后的状态。

## 5. 和 LLM 八股的对应

| 具身概念 | LLM 里的对应 |
|---|---|
| BC / 模仿学习 | [SFT](../../notes/06-post-training/sft/01-sft-basics.md) |
| compounding error | [exposure bias](../../notes/06-post-training/distill/02-sft-and-kd.md#3-exposure-biassft-真正的病) |
| 世界模型 | next-token prediction 就是一维世界模型 |
| VLA backbone | [VLM 架构](../../notes/07-vlm/01-architecture.md) |
| 具身 RL | [RL 目录](../../notes/06-post-training/rl/00-map.md) |

## 自测

**1.** 具身和 LLM 最本质的五个差异？

> **答：** ① 输出是**连续动作**而非离散 token；② **实时闭环**（10–1000 Hz）；③ 错误代价是撞坏硬件/伤人、**不可回退**；④ **数据极贵**（遥操作），比互联网数据少 6–8 个数量级；⑤ sim2real、跨本体、跨场景**全是分布迁移**。
> 一句话：LLM 缺推理，具身缺数据和闭环。

**2.** 三种范式各自赌什么、卡在哪？

> **答：** **模块化**赌每个模块都够准，卡在误差累积、感知给不出精确位姿、接触任务难建模；**端到端 VLA** 赌数据够多就能学到，卡在机器人数据比互联网少 6–8 个数量级；**世界模型 + 规划**赌学 dynamics 比学 policy 省数据（动力学任务无关、可用无标注视频学），卡在长 horizon 误差放大和规划实时性。
> **分层**是现在的实用主流：VLM 出子目标，低层策略或传统控制器执行。

**3.** compounding error 是什么？它和 LLM 里的什么问题同构？

> **答：** BC 每步有小误差 → 进入训练分布外的状态 → 误差更大 → 雪崩，随步数**平方级**增长。
> 它和 LLM 的 **exposure bias** 完全同构：SFT/BC 只在专家（正确）轨迹上训练，模型没见过"自己犯错之后"的状态。所以 OPD 那套 on-policy 思路在具身里同样成立，action chunking 也是针对它的。

**4.** 具身概念和 LLM 八股的对应关系？

> **答：** BC ↔ SFT；compounding error ↔ exposure bias；世界模型 ↔ next-token prediction（一维世界模型）；VLA backbone ↔ VLM 架构；具身 RL ↔ LLM RL。
> **很多结论能直接搬，差别在「动作连续」和「rollout 极贵」这两点上。**
