# JEPA 系列：在表示空间预测

> **JEPA = Joint-Embedding Predictive Architecture。**
> 一句话主张：**不要在像素空间重建，要在表示空间预测。**

## 1. 动机：像素重建浪费在哪

给一段视频让模型预测下一帧。画面里有：
- 物体的位置和运动 —— **可预测，而且是我们要的**
- 树叶的抖动、噪点、纹理细节 —— **本质不可预测**

像素级重建（MAE、视频生成）的 loss 会**平等地惩罚所有像素**，于是模型把大量容量花在拟合那些不可预测的高频细节上。

$$\boxed{\text{LeCun 的论断：世界在像素层面有太多不可预测的细节，把它们建模出来是浪费}}$$

JEPA 的做法是：先把 target 也编码成表示，**在表示空间里做预测**。表示本身会丢掉不可预测的细节，于是预测任务变得可做，容量集中在语义和结构上。

## 2. 结构

```text
        ┌──────────────┐
 x_ctx →│ context enc  │→ s_ctx ──┐
        └──────────────┘          │
                            ┌─────▼─────┐        ŝ_tgt
                            │ predictor │──────────┐
                            └───────────┘          │  L = ‖ŝ_tgt − s_tgt‖²
        ┌──────────────┐                           │
 x_tgt →│ target enc   │→ s_tgt ───────────────────┘
        │ (EMA, sg)    │
        └──────────────┘
```

三个部件：

| 部件 | 作用 |
|---|---|
| **context encoder** | 编码可见部分，正常反向传播 |
| **target encoder** | 编码被遮住的部分，**参数是 context encoder 的 EMA，且 stop-gradient** |
| **predictor** | 从 context 表示 + 位置信息，预测 target 的表示 |

$$\theta_{\text{tgt}}\leftarrow m\,\theta_{\text{tgt}}+(1-m)\,\theta_{\text{ctx}}$$

## 3. 卡点：为什么不会坍缩

如果两个 encoder 都可训练、loss 是 $\|s_{\text{ctx}}-s_{\text{tgt}}\|^2$，那么**把所有输入映射成同一个常数向量**就能让 loss 为 0。这就是 representation collapse。

对比学习靠**负样本**避免它（不同图必须离得远）。JEPA 没有负样本，靠的是**不对称性**：

1. **EMA + stop-gradient**：target encoder 不接收梯度，它是 context encoder 的滑动平均。student 追一个"慢一拍"的自己，无法通过共同退化到常数来作弊。
2. **predictor 的存在**：预测是从 context 到 target 的一个**非平凡映射**，如果表示退化成常数，predictor 就没有可用信息（这是一种隐式正则）。
3. 有些变体还会加 **centering / sharpening**（DINO 的做法）或方差-协方差正则（VICReg）。

$$\boxed{\text{对比学习靠负样本防坍缩；JEPA 靠 EMA + stop-gradient 的不对称性}}$$

## 4. 和 MAE、对比学习的区别

| | MAE | 对比学习（SimCLR/MoCo） | **JEPA** |
|---|---|---|---|
| 预测什么 | **像素** | 不预测，只拉近/推远 | **表示** |
| 需要负样本 | 否 | **是**（或 MoCo 的队列） | 否 |
| 需要强增广 | 否 | **是**（增广定义了不变性） | 弱 |
| 主要开销 | decoder | 大 batch / 队列 | predictor |
| 学到的表示 | 偏低层，线性探针一般 | 偏全局语义 | 偏语义 + 结构 |
| 生成能力 | 有（能重建） | 无 | **无** |

一个精确的说法：**MAE 是 JEPA 的一个特例**，只不过它的 "target encoder" 是恒等映射（直接拿像素当 target）。

## 5. I-JEPA

图像版。做法：

1. 从一张图里取一个 **context block**（一大块可见区域）
2. 取若干个 **target block**（其他区域，互不重叠）
3. context encoder 编码 context；target encoder 编码整张图，取出 target block 位置的表示
4. predictor 拿着 context 表示 + target 的**位置信息**（mask token + 位置编码），预测每个 target block 的表示
5. loss 是表示空间的 L2

关键设计：
- target block 要**足够大且语义完整**（不能是零散的几个 patch），否则任务退化成低层纹理外推
- context 要**足够大**，否则信息不足
- 不需要手工设计的数据增广（这是相对对比学习的一大优势，因为增广隐含了人为的不变性假设）

## 6. V-JEPA / V-JEPA 2

视频版，把 mask 从 2D 块换成**时空块（tube）**：遮住某些空间区域在**连续若干帧**上的内容，逼模型学运动而不是单帧纹理。

**V-JEPA 2** 的两阶段：

| 阶段 | 数据 | 做什么 |
|---|---|---|
| 预训练 | 百万小时级互联网视频，**无动作标注** | 学通用的视频表示和隐式物理直觉 |
| **后训练（V-JEPA 2-AC）** | 少量（几十小时）机器人交互数据，**有动作** | 学**动作条件**的 latent 动力学 $s_{t+1}=f(s_t,a_t)$ |

后训练之后就能直接拿来做**规划**：

```text
给定当前观测 s_t 和目标图像 s_goal
  → 在动作空间里搜索（CEM / MPPI）
  → 用 latent 动力学 rollout 出 ŝ_{t+H}
  → 选让 ‖ŝ_{t+H} − s_goal‖ 最小的动作序列
  → 执行第一步，重新规划（MPC）
```

$$\boxed{\text{V-JEPA 2-AC 的意义：用无标注视频学表示，用极少动作数据学动力学，然后 zero-shot 规划}}$$

这直接呼应了具身最大的痛点 —— **动作数据极贵**。

## 7. 在具身里的位置

放回 [世界模型的三条路线](../03-world-model/00-map.md)：

| 路线 | 在哪个空间预测 | 代表 |
|---|---|---|
| pixel / video 生成 | 像素 | Genie、Sora-like |
| latent dynamics | 学出来的 latent（但仍有重建 loss） | Dreamer |
| **JEPA** | **纯表示空间，无重建** | V-JEPA 2 |

三者的取舍：能不能可视化、要不要重建监督、样本效率。JEPA 样本效率高但**没法生成画面**，调试和评估都更困难。

## 8. 局限与争议

- **没有生成能力**：不能可视化模型"想象"的东西，debug 困难，也做不了需要生成的下游任务
- **表示评估困难**：好不好只能靠下游探针（linear probe、attentive probe）间接衡量
- **预测目标是移动的**：target encoder 在 EMA 更新，训练动力学比固定 target 复杂
- **是不是真的"理解物理"有争议**：能预测表示不等于有因果模型
- 相比大规模视频生成模型，**规模化的证据还不够多**

## 自测

**1.** JEPA 的核心主张是什么？它认为像素重建浪费在哪？

> **答：** **在表示空间预测，而不是在像素空间重建。**
> 像素级 loss 平等惩罚所有像素，而画面里树叶抖动、噪点、纹理这些**本质不可预测**的高频细节占了大头，模型会把大量容量浪费在拟合它们上。表示空间天然丢掉这些细节，预测任务才落在语义和结构上。

**2.** 画出 JEPA 的三个部件，说明各自的梯度情况。

> **答：** **context encoder**（编码可见部分，正常反传）、**target encoder**（编码被遮部分，**EMA 更新 + stop-gradient，不接收梯度**）、**predictor**（从 context 表示 + 位置信息预测 target 表示）。
> loss 是表示空间的 L2：$\|\hat s_{\text{tgt}}-s_{\text{tgt}}\|^2$，$\theta_{\text{tgt}}\leftarrow m\theta_{\text{tgt}}+(1-m)\theta_{\text{ctx}}$。

**3.** 为什么不会坍缩？和对比学习的防坍缩机制有什么不同？

> **答：** 如果两个 encoder 都可训练，把所有输入映射成同一常数就能让 loss 为 0，这就是坍缩。
> 对比学习靠**负样本**（不同图必须离得远）；JEPA 没有负样本，靠**不对称性**：① EMA + stop-gradient，student 追一个"慢一拍"的自己，无法共同退化；② predictor 的存在使预测成为非平凡映射，表示退化则无信息可用；③ 部分变体加 centering/sharpening 或方差-协方差正则。

**4.** MAE / 对比学习 / JEPA 的对照？为什么说 MAE 是 JEPA 的特例？

> **答：** MAE 预测**像素**、无需负样本、有生成能力；对比学习不预测只拉近推远、**需要负样本和强增广**；JEPA 预测**表示**、无需负样本、**没有生成能力**。
> **MAE 是 JEPA 的特例**：它的 target encoder 是恒等映射（直接拿像素当 target）。

**5.** I-JEPA 的 target block 为什么要足够大？

> **答：** target block 太小或太零散时，任务会退化成**低层纹理外推**（从周围像素猜纹理），学不到语义。要求 block 足够大且语义完整，才逼模型用高层语义去预测。
> 同理 context 也要足够大，否则信息不足。

**6.** V-JEPA 2 的两阶段各用什么数据、学什么？

> **答：** **预训练**用百万小时级互联网视频（**无动作标注**），学通用视频表示和隐式物理直觉；**后训练 V-JEPA 2-AC** 用少量（几十小时）机器人交互数据（**有动作**），学动作条件的 latent 动力学 $s_{t+1}=f(s_t,a_t)$。
> 意义在于：**用无标注视频学表示、用极少动作数据学动力学**，直接命中具身"动作数据极贵"的痛点。

**7.** V-JEPA 2-AC 怎么做规划？

> **答：** MPC 式：给定当前观测和目标图像 → 在动作空间用 CEM / MPPI 搜索 → 用 latent 动力学 rollout 出 $\hat s_{t+H}$ → 选让 $\|\hat s_{t+H}-s_{\text{goal}}\|$ 最小的动作序列 → **只执行第一步，然后重新规划**。

**8.** JEPA 相比 pixel 世界模型的取舍？它的四个局限是什么？

> **答：** 样本效率高、不浪费容量在细节上；但**没有生成能力**。
> 局限：① 不能可视化模型的"想象"，debug 和评估困难；② 表示好坏只能靠下游探针间接衡量；③ 预测目标在 EMA 更新中**移动**，训练动力学更复杂；④ 能预测表示不等于有因果物理模型，"是否真的理解物理"有争议；⑤ 相比大规模视频生成，规模化证据还不够多。
