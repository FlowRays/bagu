# 具身评测

## 1. 仿真 benchmark

| Benchmark | 特点 |
|---|---|
| **LIBERO** | 终身学习设定，任务分组清晰，社区常用 |
| **SimplerEnv** | 专门做**仿真-真机对齐**，让仿真评测能预测真机表现 |
| **CALVIN** | 长程语言条件任务 |
| **Meta-World** | 50 个操作任务，多任务/元学习 |
| **RoboCasa** | 大规模厨房场景 |

## 2. 真机评测的难点

| 难点 | 说明 |
|---|---|
| **方差大** | 同一策略跑 10 次成功率可能 3/10 到 7/10，必须报试验次数和置信区间 |
| **不可复现** | 物体初始位姿、光照、磨损每天都不同 |
| **人工成本** | 每次试验都要人复位场景 |
| **判定主观** | "算不算完成"需要明确的成功判据 |

$$\boxed{\text{只报成功率而不报试验次数，这个数字没有意义}}$$

## 3. 该报哪些数

- **成功率 + 试验次数 + 方差**（至少 20 次，最好报置信区间）
- **效率**：完成时间 / 步数
- **安全**：碰撞次数、超力次数
- **泛化维度**分开报：新物体 / 新场景 / 新指令 / 新本体

## 4. 常见陷阱

1. **仿真涨点不等于真机涨点** —— 这是 SimplerEnv 存在的理由
2. **初始位姿分布太窄**：只在物体固定摆放时测，泛化被高估
3. **cherry-picking 视频**：放的是最好的一次
4. **训练集里有同款物体**：泛化被高估，需要严格划分 unseen
5. **成功判据太松**：碰到了就算成功 vs 稳定抓起并放到位

## 5. 和 LLM 评测的对照

| | LLM | 具身 |
|---|---|---|
| 可复现性 | 固定 seed 基本可复现 | **物理环境无法完全复现** |
| 评测成本 | 跑一遍 benchmark 几小时 | 真机几天，还要人守着 |
| 污染 | 训练集混进评测集 | 训练场景/物体混进评测 |
| 判定 | exact match / LLM judge | 人工判定 / 传感器判据 |

[LLM 评测那一篇](../../notes/08-eval-harness/01-eval.md) 里说的 setting 披露、去污染、cherry-picking 问题，在具身里**只会更严重**。

## 自测

**1.** 五个常用仿真 benchmark 各自的特点？SimplerEnv 特殊在哪？

> **答：** LIBERO（终身学习设定）、**SimplerEnv**（专做**仿真-真机对齐**，让仿真评测能预测真机表现）、CALVIN（长程语言条件）、Meta-World（50 个操作任务）、RoboCasa（大规模厨房场景）。
> SimplerEnv 的特殊之处在于它的目标不是"再造一个难 benchmark"，而是**让仿真数字可信**。

**2.** 真机评测的四个难点？

> **答：** ① **方差大**（同策略 10 次可能 3/10 到 7/10）；② **不可复现**（物体位姿、光照、磨损每天都变）；③ **人工成本**（每次要人复位）；④ **判定主观**（成功判据要明确）。

**3.** 该报哪些数？

> **答：** **成功率 + 试验次数 + 方差/置信区间**（至少 20 次）、**效率**（完成时间/步数）、**安全**（碰撞、超力次数）、**泛化维度分开报**（新物体/新场景/新指令/新本体）。
> 只报成功率不报试验次数，这个数字没有意义。

**4.** 五个常见陷阱？

> **答：** ① 仿真涨点不等于真机涨点；② 初始位姿分布太窄导致泛化被高估；③ cherry-picking 视频；④ 训练集里有同款物体（unseen 划分不严）；⑤ 成功判据太松（碰到就算 vs 稳定抓起放到位）。

**5.** 和 LLM 评测比，具身评测哪些问题更严重？

> **答：** **可复现性**（物理环境无法完全复现 vs 固定 seed 基本可复现）、**评测成本**（真机几天且要人守 vs 几小时）、**判定**（人工/传感器 vs exact match）。
> LLM 评测里说的 setting 披露、去污染、cherry-picking 在具身里只会更严重，因为验证成本高到别人几乎无法复现你的数字。
