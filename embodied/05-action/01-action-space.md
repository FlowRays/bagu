# 动作空间与表示

> **VLA 和 LLM 差别最大的一段。** LLM 输出离散 token，机器人输出连续、有物理量纲、有安全后果的动作。
> 面试问 VLA，动作这块几乎必问。
> 没做过机器人的话先看 [01b 动作空间从零](01b-action-space-from-zero.md)：DoF、关节与连杆、FK/IK、旋转表示的手算，都在那篇。

## 1. 控制什么：三个层次

| 层次 | 动作是什么 | 特点 |
|---|---|---|
| **关节空间** | 每个关节的 position / velocity / **torque** | 最底层；torque 控制最灵活但最难学 |
| **末端空间**（EE） | 末端执行器的位姿 $(x,y,z,\text{rot})$ | 语义清楚、跨本体可迁移；需要 IK 转成关节指令 |
| **高层** | "把杯子放到桌上" | 交给 VLM / 规划器，不是 action head 的事 |

VLA 绝大多数在**末端空间**输出，因为它和视觉观测的空间关系直接、而且换一台机械臂时末端语义不变（**cross-embodiment 的基础**）。

## 2. 姿态怎么表示

平移是 3 维没有争议，**旋转的表示方式是个坑**：

| 表示 | 维度 | 问题 |
|---|---|---|
| 欧拉角 | 3 | **万向锁**、不连续、多解 |
| 四元数 | 4 | $q$ 和 $-q$ 表示同一旋转（**双重覆盖**），回归时会撕裂 |
| 旋转矩阵 | 9 | 连续但有正交约束 |
| **6D 表示** | 6 | 取旋转矩阵前两列，用 Gram-Schmidt 还原。**连续、无歧义，现在的主流** |

$$\boxed{\text{回归旋转要用 6D 表示，别用欧拉角或裸四元数}}$$

原因是神经网络回归需要目标空间**连续**：$SO(3)$ 到任何 $\le4$ 维实向量空间都不存在连续双射，所以欧拉角和四元数必然在某处不连续或多值，回归时会在那里产生巨大误差。

## 3. Delta 还是 absolute

| | delta（增量） | absolute（绝对位姿） |
|---|---|---|
| 输出 | $\Delta x$，相对当前位姿 | 目标位姿本身 |
| 分布 | 以 0 为中心、尺度小，**好学** | 依赖场景绝对坐标 |
| 误差 | **会累积**（open-loop 漂移） | 不累积 |
| 泛化 | 对起始位姿不敏感，泛化好 | 需要见过那个绝对区域 |

实践上 **delta 更常见**（尤其配合 [action chunking](03-chunking-and-realtime.md)），但要注意：

- delta 必须明确**参考系**（base / camera / tool frame）和**时间基准**（相对上一帧还是相对当前实际位姿）
- 长 horizon 下 delta 累积漂移，靠闭环重规划纠正

## 4. Gripper 与力

- **gripper**：通常单独一维，可以是连续开合度也可以是二值。二值化后往往更好学（它本质是离散决策）
- **力/阻抗控制**：接触任务（插孔、擦拭、开门）光靠位置控制会顶死或打滑，需要力控或阻抗控制。这类动作空间更难学，数据也更难采

## 5. 归一化

动作各维量纲差别巨大（位移 cm 级、旋转 rad 级、gripper 0/1），**必须归一化**否则 loss 被大量纲的维度主导。

常见做法：按训练集统计的分位数（如 1%–99%）线性映射到 $[-1,1]$，比用 min-max 更抗离群值。

$$\boxed{\text{归一化的统计量属于模型的一部分，推理时必须用同一套反归一化}}$$

这是部署时最常见的低级 bug 来源之一：换了数据集重新算了统计量，但没同步到推理端。

## 6. 观测侧对应的东西

动作不是孤立的，和它配套的是：

- **多相机**：第三人称 + **腕部相机**（wrist camera 对精细操作几乎是必需的）
- **本体感知（proprioception）**：当前关节角、末端位姿、gripper 状态。通常直接拼进 token 序列或作为额外 embedding
- **历史**：几帧图像 + 几步动作历史，缓解部分可观测

## 7. 一个常被问的问题：为什么不直接用 IK + 传统规划

因为：
1. 传统规划需要**精确的物体位姿和几何**，而感知给不出（尤其是柔性物、透明物、堆叠场景）
2. 接触丰富的任务难以建模
3. 语言指令到目标位姿的映射本身就需要语义理解

但反过来，**纯端到端也不是最优**：现在实用系统常是分层的 —— VLM 出子目标，低层用学习策略或传统控制器执行。

## 自测

**1.** 三个控制层次分别是什么？VLA 主要在哪一层输出，为什么？

> **答：** **关节空间**（position/velocity/torque）、**末端空间**（EE 位姿）、**高层语义目标**。
> VLA 绝大多数在**末端空间**输出，因为它和视觉观测的空间关系直接，而且换一台机械臂时末端语义不变 —— 这是 **cross-embodiment 泛化的基础**。

**2.** 旋转为什么要用 6D 表示？欧拉角和四元数各有什么问题？

> **答：** 神经网络回归需要目标空间**连续**，而 $SO(3)$ 到任何 $\le4$ 维实向量空间**不存在连续双射**，所以低维表示必然在某处不连续或多值。
> 欧拉角有**万向锁**、不连续、多解；四元数有**双重覆盖**（$q$ 和 $-q$ 是同一旋转），回归时会撕裂。
> **6D 表示**取旋转矩阵前两列、用 Gram-Schmidt 还原，连续且无歧义，是现在的主流。

**3.** delta 和 absolute 的取舍？delta 要注意什么？

> **答：** delta 以 0 为中心、尺度小、**好学**、对起始位姿不敏感泛化好，但**误差会累积**（open-loop 漂移）；absolute 不累积但依赖场景绝对坐标、泛化差。
> 实践上 delta 更常见，但必须明确**参考系**（base/camera/tool）和**时间基准**（相对上一帧还是相对当前实际位姿），并靠闭环重规划纠正漂移。

**4.** 动作归一化为什么必须做？常见做法？最容易出的 bug 是什么？

> **答：** 各维量纲差别巨大（位移 cm、旋转 rad、gripper 0/1），不归一化 loss 会被大量纲维度主导。
> 常见做法是按训练集的分位数（1%–99%）线性映射到 $[-1,1]$，比 min-max 抗离群值。
> **最常见的 bug**：归一化统计量是模型的一部分，换数据集重算后没同步到推理端的反归一化。

**5.** 为什么 wrist camera 对精细操作几乎必需？

> **答：** 第三人称相机在末端接近目标时经常被机械臂自身遮挡，而且分辨率不足以看清厘米级的对齐关系。腕部相机随末端移动，始终能看到接触点附近的细节。

**6.** 为什么不直接用 IK + 传统规划？为什么纯端到端也不是最优？

> **答：** 传统规划需要**精确的物体位姿和几何**，感知给不出（柔性物、透明物、堆叠）；接触丰富的任务难建模；语言到目标位姿的映射本身需要语义理解。
> 但纯端到端数据代价太高、可解释性差，所以现在实用系统常**分层**：VLM 出子目标，低层用学习策略或传统控制器执行。
