## K-Means 聚类

`中等` ｜ **思路**：随机选 k 个点做初始中心，然后反复「分配 + 求均值」直到中心不动。

```python
class KMeans:
    def fit(self, X, k, n_iter=100, seed=0):
        X = np.asarray(X, float)
        rng = np.random.default_rng(seed)
        C = X[rng.choice(len(X), k, replace=False)]
        for _ in range(n_iter):
            d = ((X[:, None, :] - C[None]) ** 2).sum(-1)      # (n,k)
            lab = d.argmin(1)
            newC = np.array([X[lab == j].mean(0) if (lab == j).any() else C[j]
                             for j in range(k)])
            if np.allclose(newC, C):
                break
            C = newC
        return C, lab
```

**复杂度**：O(n·k·d·iter)

**易错**：空簇要保留原中心，否则 `mean` 会得到 nan；距离用广播算，别写三重循环。

## 逻辑回归

`中等` ｜ **思路**：和线性回归只差一个 sigmoid。关键是记住交叉熵对 logit 的梯度就是 `p - y`，不用再乘 sigmoid 导数。

```python
class LogisticRegression:
    def fit(self, X, y, lr=0.1, epochs=1000):
        X, y = np.asarray(X, float), np.asarray(y, float)
        n, d = X.shape
        w, b = np.zeros(d), 0.0
        for _ in range(epochs):
            p = 1 / (1 + np.exp(-(X @ w + b)))
            g = p - y                                          # dL/dz
            w -= lr * (X.T @ g) / n
            b -= lr * g.mean()
        self.w, self.b = w, b
        return w, b

    def predict_proba(self, X):
        return 1 / (1 + np.exp(-(np.asarray(X, float) @ self.w + self.b)))
```

**复杂度**：O(n·d·epochs)

**易错**：梯度要除以 n；`w` 和 `b` 的梯度分别是 `Xᵀg/n` 和 `mean(g)`。

## PCA

`中等` ｜ **思路**：中心化后做 SVD，右奇异向量就是主成分方向。

```python
class PCA:
    def fit_transform(self, X, k):
        X = np.asarray(X, float)
        Xc = X - X.mean(0)
        # SVD 比手算协方差特征分解更稳
        U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
        W = Vt[:k].T                                           # (d,k)
        return Xc @ W, W
```

**复杂度**：O(n·d·min(n,d))

**易错**：**必须先减均值**；用 SVD 比手算协方差矩阵再特征分解更稳，也不用担心对称性误差。

## 线性回归

`中等` ｜ **思路**：最小二乘闭式解。拼一列 1 把偏置并进权重，直接 `lstsq`。

```python
class LinearRegression:
    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y, float)
        A = np.hstack([X, np.ones((len(X), 1))])               # 拼偏置列
        theta, *_ = np.linalg.lstsq(A, y, rcond=None)
        return theta[:-1], theta[-1]
```

**复杂度**：O(n·d²)

**易错**：`lstsq` 比 `inv(XᵀX)·Xᵀy` 稳，后者在共线时会炸。

## KNN

`中等` ｜ **思路**：算全部距离，取最近 k 个，投票。

```python
class KNN:
    def predict(self, X_train, y_train, X_test, k):
        X_train, y_train = np.asarray(X_train, float), np.asarray(y_train)
        X_test = np.asarray(X_test, float)
        d = ((X_test[:, None, :] - X_train[None]) ** 2).sum(-1)
        idx = np.argsort(d, 1)[:, :k]
        return np.array([np.bincount(y_train[i]).argmax() for i in idx])
```

**复杂度**：O(n_test·n_train·d)

**易错**：`bincount` 要求标签是非负整数；并列时取最小类别下标。

## AUC 计算

`中等` ｜ **思路**：**秩和法**：AUC = (正样本秩和 − P(P+1)/2) / (P·N)。等价于「随机取一正一负，正的分数更高的概率」。

```python
class AUC:
    def auc(self, y_true, y_score):
        y = np.asarray(y_true, int)
        s = np.asarray(y_score, float)
        # 秩和法，平均秩处理并列分数
        order = np.argsort(s, kind="mergesort")
        r = np.empty(len(s), float)
        r[order] = np.arange(1, len(s) + 1)
        ss = s[order]
        i = 0
        while i < len(ss):                                     # 并列取平均秩
            j = i
            while j + 1 < len(ss) and ss[j + 1] == ss[i]:
                j += 1
            if j > i:
                r[order[i:j + 1]] = r[order[i:j + 1]].mean()
            i = j + 1
        P, N = (y == 1).sum(), (y == 0).sum()
        if P == 0 or N == 0:
            return 0.5
        return (r[y == 1].sum() - P * (P + 1) / 2) / (P * N)
```

**复杂度**：O(n log n)

**易错**：**并列分数必须取平均秩**，这是通过率只有 27% 的主因；只有一类时没有定义，返回 0.5。
