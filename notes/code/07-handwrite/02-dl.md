## 多通道卷积计算

`中等` ｜ **思路**：滑窗取 patch，和整个卷积核做 `tensordot` 一次算完所有输出通道。

```python
def conv2d(x, w, b=None, stride=1, padding=0):
    """x (N,Cin,H,W), w (Cout,Cin,kh,kw) -> (N,Cout,Ho,Wo)。"""
    x = np.asarray(x, float); w = np.asarray(w, float)
    N, Ci, H, W = x.shape; Co, _, kh, kw = w.shape
    p = padding
    if p: x = np.pad(x, ((0, 0), (0, 0), (p, p), (p, p)))
    Ho = (H + 2 * p - kh) // stride + 1
    Wo = (W + 2 * p - kw) // stride + 1
    out = np.zeros((N, Co, Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            patch = x[:, :, i * stride:i * stride + kh, j * stride:j * stride + kw]
            out[:, :, i, j] = np.tensordot(patch, w, axes=([1, 2, 3], [1, 2, 3]))
    if b is not None:
        out += np.asarray(b, float).reshape(1, -1, 1, 1)
    return out
```

**复杂度**：O(N·Co·Ci·Ho·Wo·kh·kw)

**易错**：输出尺寸 `(H+2p-k)//s+1`；padding 只补 H/W 两维，别把 batch 和通道也补了。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def conv2d(x, w, b=None, stride=1, padding=0):
    return F.conv2d(x, w, b, stride=stride, padding=padding)   # 注意这是相关不是卷积
```

**torch 侧注意**：`F.conv2d` 是**相关**不是卷积（不翻转核），和 numpy 手写版一致。

## Sigmoid

`中等` ｜ **思路**：按符号分段算，避免 `exp` 溢出。

```python
def sigmoid(x):
    x = np.asarray(x, float)
    # 分段避免 exp 溢出
    out = np.empty_like(x)
    pos, neg = x >= 0, x < 0
    out[pos] = 1 / (1 + np.exp(-x[pos]))
    e = np.exp(x[neg]); out[neg] = e / (1 + e)
    return out
```

**复杂度**：O(n)

**易错**：直接写 `1/(1+exp(-x))` 在 x 很负时 `exp` 会溢出；x≥0 和 x<0 分开写。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def sigmoid(x):
    return torch.sigmoid(x)                    # 内部已做分段，不会溢出
```

**torch 侧注意**：`torch.sigmoid` 内部已做分段，不会溢出。

## Softmax

`中等` ｜ **思路**：减去每行最大值再取 exp。

```python
def softmax(x, axis=-1):
    x = np.asarray(x, float)
    x = x - x.max(axis, keepdims=True)          # 减最大值防溢出
    e = np.exp(x)
    return e / e.sum(axis, keepdims=True)
```

**复杂度**：O(n)

**易错**：**不减最大值必炸**；减了之后结果不变，因为分子分母同乘一个常数。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def softmax(x, dim=-1):
    return F.softmax(x, dim=dim)               # 内部已减最大值
```

**torch 侧注意**：`F.softmax(x, dim=-1)` 的 `dim` 必须显式写，省略会警告；内部已减最大值。

**原理**：[Softmax 与 CE 的梯度 p−q](../../06-post-training/distill/01-entropy-ce-kl-jsd.md)

## 交叉熵损失

`中等` ｜ **思路**：log_softmax 之后按标签取值取负。

```python
def cross_entropy(logits, labels):
    """logits (N,C)，labels (N,) 类别下标；返回 batch 平均 loss。"""
    logits = np.asarray(logits, float); labels = np.asarray(labels, int)
    z = logits - logits.max(1, keepdims=True)
    logp = z - np.log(np.exp(z).sum(1, keepdims=True))   # log_softmax
    return -logp[np.arange(len(labels)), labels].mean()
```

**复杂度**：O(N·C)

**易错**：不要先 softmax 再 log，会丢精度；直接 `z - log(sum(exp(z)))`。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def cross_entropy(logits, labels):
    return F.cross_entropy(logits, labels)     # 直接吃 logits，别自己先 softmax
```

**torch 侧注意**：`F.cross_entropy` **直接吃 logits**，千万别自己先 softmax 再传进去（等于做了两次）。

**原理**：[交叉熵 = 熵 + KL](../../06-post-training/distill/01-entropy-ce-kl-jsd.md)

## MLP训练

`中等` ｜ **思路**：前向 → 交叉熵 → 反向 → 更新，循环若干轮。复用下面那道反向传播。

```python
def train_mlp(X, y, hidden=16, epochs=300, lr=0.1, seed=0):
    rng = np.random.default_rng(seed)
    D, C = X.shape[1], int(y.max()) + 1
    W1 = rng.normal(0, .1, (D, hidden)); b1 = np.zeros(hidden)
    W2 = rng.normal(0, .1, (hidden, C)); b2 = np.zeros(C)
    for _ in range(epochs):
        loss, dW1, db1, dW2, db2 = mlp_backward(X, y, W1, b1, W2, b2)
        W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    return loss, (W1, b1, W2, b2)
```

**复杂度**：O(epochs·N·D·H)

**易错**：权重不能全 0 初始化，否则隐藏单元对称永远学不开。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def train_mlp(X, y, hidden=16, epochs=300, lr=0.1, seed=0):
    torch.manual_seed(seed)
    model = torch.nn.Sequential(
        torch.nn.Linear(X.size(1), hidden),
        torch.nn.ReLU(),
        torch.nn.Linear(hidden, int(y.max()) + 1),
    ).double()
    opt = torch.optim.SGD(model.parameters(), lr=lr)
    for _ in range(epochs):
        opt.zero_grad()
        loss = F.cross_entropy(model(X), y)
        loss.backward(); opt.step()
    return loss.item(), model
```

## Layer Normalization

`中等` ｜ **思路**：在**特征维**上减均值除标准差，再乘 γ 加 β。

```python
def layer_norm(x, gamma, beta, eps=1e-5):
    x = np.asarray(x, float)
    mu = x.mean(-1, keepdims=True)
    var = x.var(-1, keepdims=True)              # 有偏方差
    return gamma * (x - mu) / np.sqrt(var + eps) + beta
```

**复杂度**：O(N·D)

**易错**：用有偏方差（除 N 不是 N−1）；`eps` 在开方**里面**。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def layer_norm(x, gamma, beta, eps=1e-5):
    return F.layer_norm(x, (x.size(-1),), weight=gamma, bias=beta, eps=eps)
```

**torch 侧注意**：`F.layer_norm` 第二个参数是 `normalized_shape`，传 `(x.size(-1),)` 这个**元组**，不是整数。

## Batch Normalization

`中等` ｜ **思路**：和 LayerNorm 同一个式子，只是统计量沿 **batch 维**求。

```python
def batch_norm(x, gamma, beta, eps=1e-5):
    """训练态：对 batch 维求统计量。x (N,D)。"""
    x = np.asarray(x, float)
    mu = x.mean(0, keepdims=True)
    var = x.var(0, keepdims=True)
    return gamma * (x - mu) / np.sqrt(var + eps) + beta
```

**复杂度**：O(N·D)

**易错**：训练用 batch 统计、推理用滑动平均，这是它和 LayerNorm 最大的工程差别；LLM 不用它正是因为推理时 batch/seq 一直变。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def batch_norm(x, gamma, beta, eps=1e-5):
    # training=True 用当前 batch 统计量；推理要传 running_mean/var 并 training=False
    return F.batch_norm(x, None, None, weight=gamma, bias=beta, training=True, eps=eps)
```

**torch 侧注意**：`F.batch_norm` 要显式传 `training=True` 才用当前 batch 统计量；推理时要传 `running_mean/var`。

**原理**：[为什么 LLM 不用 BatchNorm](../../03-training-fundamentals/01-memory-accounting.md)

## IoU Loss

`简单` ｜ **思路**：交集面积 / 并集面积，loss = 1 − IoU。

```python
def iou_loss(boxes1, boxes2, eps=1e-7):
    """box = (x1,y1,x2,y2)，返回 1 - IoU 的均值。"""
    a = np.asarray(boxes1, float); b = np.asarray(boxes2, float)
    x1 = np.maximum(a[..., 0], b[..., 0]); y1 = np.maximum(a[..., 1], b[..., 1])
    x2 = np.minimum(a[..., 2], b[..., 2]); y2 = np.minimum(a[..., 3], b[..., 3])
    inter = np.clip(x2 - x1, 0, None) * np.clip(y2 - y1, 0, None)
    area_a = np.clip(a[..., 2] - a[..., 0], 0, None) * np.clip(a[..., 3] - a[..., 1], 0, None)
    area_b = np.clip(b[..., 2] - b[..., 0], 0, None) * np.clip(b[..., 3] - b[..., 1], 0, None)
    iou = inter / (area_a + area_b - inter + eps)
    return float((1 - iou).mean())
```

**复杂度**：O(n)

**易错**：交集边长要 `clip(·, 0, None)`，两框不相交时会得到负数；分母加 eps。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def iou_loss(boxes1, boxes2, eps=1e-7):
    x1 = torch.maximum(boxes1[..., 0], boxes2[..., 0])
    y1 = torch.maximum(boxes1[..., 1], boxes2[..., 1])
    x2 = torch.minimum(boxes1[..., 2], boxes2[..., 2])
    y2 = torch.minimum(boxes1[..., 3], boxes2[..., 3])
    inter = (x2 - x1).clamp(min=0) * (y2 - y1).clamp(min=0)
    a1 = (boxes1[..., 2] - boxes1[..., 0]).clamp(min=0) * (boxes1[..., 3] - boxes1[..., 1]).clamp(min=0)
    a2 = (boxes2[..., 2] - boxes2[..., 0]).clamp(min=0) * (boxes2[..., 3] - boxes2[..., 1]).clamp(min=0)
    return (1 - inter / (a1 + a2 - inter + eps)).mean()
```

## 梯度下降求平方根

`中等` ｜ **思路**：对 f(x)=(x²−n)² 做梯度下降，f'(x)=4x(x²−n)。

```python
def sqrt_gd(n, lr=0.05, epochs=100000, tol=1e-13):
    """最小化 f(x)=(x^2-n)^2，f'(x)=4x(x^2-n)。
    步长必须随 n 缩放，否则 n 一大第一步就冲出去发散。"""
    if n < 0: raise ValueError("n must be >= 0")
    if n == 0: return 0.0
    x, step = 1.0, lr / (1.0 + n)
    for _ in range(epochs):
        g = 4 * x * (x * x - n)
        x -= step * g
        if abs(g) < tol: break
    return x
```

**复杂度**：O(epochs)

**易错**：**步长必须随 n 缩放**，否则 n 一大第一步就冲出去发散（这题最容易翻车的点）；牛顿法 `x←(x+n/x)/2` 收敛快得多，可以顺口提一句。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def sqrt_gd(n, lr=0.05, epochs=2000):
    """用 autograd 求，不用手推梯度。"""
    x = torch.tensor(1.0, requires_grad=True)
    opt = torch.optim.SGD([x], lr=lr / (1.0 + n))
    for _ in range(epochs):
        opt.zero_grad()
        loss = (x * x - n) ** 2
        loss.backward()                        # autograd 自动算出 4x(x^2-n)
        opt.step()
    return x.item()
```

**torch 侧注意**：torch 版直接 `loss.backward()` 让 autograd 算，不用手推 `4x(x²-n)`。

## 反向传播（两层全连接网络）

`中等` ｜ **思路**：链式法则四步：`dz2 = (p − onehot)/N` → `dW2/db2` → 回传 `da1` → 经 ReLU 掩码得 `dz1` → `dW1/db1`。

```python
def mlp_backward(x, y, W1, b1, W2, b2):
    """x (N,D) -> ReLU -> softmax + CE；返回 loss 和四个梯度。"""
    x = np.asarray(x, float); y = np.asarray(y, int); N = len(x)
    z1 = x @ W1 + b1; a1 = np.maximum(z1, 0)
    z2 = a1 @ W2 + b2
    p = softmax(z2)
    zz = z2 - z2.max(1, keepdims=True)                          # log_softmax，别写 log(softmax)
    loss = -(zz - np.log(np.exp(zz).sum(1, keepdims=True)))[np.arange(N), y].mean()
    dz2 = p.copy(); dz2[np.arange(N), y] -= 1; dz2 /= N        # (p - onehot)/N
    dW2, db2 = a1.T @ dz2, dz2.sum(0)
    da1 = dz2 @ W2.T
    dz1 = da1 * (z1 > 0)
    dW1, db1 = x.T @ dz1, dz1.sum(0)
    return loss, dW1, db1, dW2, db2
```

**复杂度**：O(N·D·H)

**易错**：`dz2` 别忘了除以 N（loss 取了均值）；ReLU 的导数是 `z1 > 0` 不是 `a1 > 0`（数值上等价但写 z 更清楚）。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def mlp_backward(x, y, W1, b1, W2, b2):
    """torch 版直接让 autograd 算，重点是理解 numpy 版手推的那四个梯度。"""
    for t in (W1, b1, W2, b2):
        t.requires_grad_(True); t.grad = None
    z1 = x @ W1 + b1
    a1 = F.relu(z1)
    loss = F.cross_entropy(a1 @ W2 + b2, y)
    loss.backward()
    return loss.item(), W1.grad, b1.grad, W2.grad, b2.grad
```

**torch 侧注意**：torch 版靠 autograd，**但面试考的是 numpy 版那四个手推梯度**，别只会调 backward。

**原理**：[为什么 backward 要存 activation](../../03-training-fundamentals/01-memory-accounting.md)

## Adam 优化器

`中等` ｜ **思路**：一阶动量 + 二阶动量 + **偏差修正**。

```python
class Adam:
    def __init__(self, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
        self.lr, self.b1, self.b2, self.eps = lr, b1, b2, eps
        self.m = self.v = None; self.t = 0
    def step(self, params, grads):
        p = np.asarray(params, float); g = np.asarray(grads, float)
        if self.m is None:
            self.m = np.zeros_like(p); self.v = np.zeros_like(p)
        self.t += 1
        self.m = self.b1 * self.m + (1 - self.b1) * g
        self.v = self.b2 * self.v + (1 - self.b2) * g * g
        mh = self.m / (1 - self.b1 ** self.t)       # 偏差修正
        vh = self.v / (1 - self.b2 ** self.t)
        return p - self.lr * mh / (np.sqrt(vh) + self.eps)
```

**复杂度**：O(d)

**易错**：`t` 从 1 开始；**偏差修正不能省**，否则前几步步长严重偏小；`eps` 加在 `sqrt` 外面。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
class Adam:
    """等价于 torch.optim.Adam(params, lr, betas, eps)。"""
    def __init__(self, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
        self.lr, self.b1, self.b2, self.eps = lr, b1, b2, eps
        self.m = self.v = None; self.t = 0
    def step(self, p, g):
        if self.m is None:
            self.m = torch.zeros_like(p); self.v = torch.zeros_like(p)
        self.t += 1
        self.m = self.b1 * self.m + (1 - self.b1) * g
        self.v = self.b2 * self.v + (1 - self.b2) * g * g
        mh = self.m / (1 - self.b1 ** self.t)
        vh = self.v / (1 - self.b2 ** self.t)
        return p - self.lr * mh / (vh.sqrt() + self.eps)
```

**torch 侧注意**：手写版与 `torch.optim.Adam` 已对拍一致；面试要手写就写这个，工程里直接用官方的。

**原理**：[Adam 的 m/v 占多少显存](../../03-training-fundamentals/01-memory-accounting.md)

## 一维卷积 im2col 矩阵展开

`中等` ｜ **思路**：把每个滑窗展平成一行，卷积就变成一次矩阵乘。

```python
def im2col_1d(x, k, stride=1):
    """x (L,) 或 (C,L) -> 展开成 (num_win, C*k)，配合权重展平做矩阵乘。"""
    x = np.atleast_2d(np.asarray(x, float))     # (C,L)
    C, L = x.shape
    n = (L - k) // stride + 1
    cols = np.empty((n, C * k))
    for i in range(n):
        cols[i] = x[:, i * stride:i * stride + k].reshape(-1)
    return cols

def conv1d_im2col(x, w, stride=1):
    """w (C,k) 或 (k,)；等价于 valid 相关（不翻转核）。"""
    w = np.atleast_2d(np.asarray(w, float))
    cols = im2col_1d(x, w.shape[1], stride)
    return cols @ w.reshape(-1)
```

**复杂度**：O(n·C·k)

**易错**：im2col 是**空间换时间**，展开后有重复元素；注意这里是相关不是卷积（不翻转核）。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def im2col_1d(x, k, stride=1):
    if x.dim() == 1: x = x.unsqueeze(0)        # (C,L)
    return x.unfold(-1, k, stride).transpose(0, 1).reshape(-1, x.size(0) * k)

def conv1d_im2col(x, w, stride=1):
    if w.dim() == 1: w = w.unsqueeze(0)
    return im2col_1d(x, w.size(1), stride) @ w.reshape(-1)
```

**torch 侧注意**：`Tensor.unfold(dim, size, step)` 就是滑窗展开，比手写循环快很多。

## Linear Layer

`简单` ｜ **思路**：`x @ W + b`。

```python
class Linear:
    def forward(self, x, W, b):
        return np.asarray(x, float) @ np.asarray(W, float) + np.asarray(b, float)
```

**复杂度**：O(N·din·dout)

**易错**：留意 W 是 `(din,dout)` 还是 `(dout,din)`，PyTorch 的 `nn.Linear.weight` 是后者。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def linear(x, W, b):
    return x @ W + b                           # nn.Linear 的 weight 是 (out,in)，要 x @ W.T
```

**torch 侧注意**：`nn.Linear.weight` 的形状是 `(out_features, in_features)`，所以是 `x @ W.T`，和手写的 `x @ W` 差一个转置。

## FFN（前馈网络前向传播）

`中等` ｜ **思路**：两层线性夹一个 ReLU。

```python
def ffn(x, W1, b1, W2, b2):
    h = np.asarray(x, float) @ W1 + b1
    h = np.maximum(h, 0)                        # ReLU
    return h @ W2 + b2
```

**复杂度**：O(N·d·d_ff)

**易错**：中间维一般是 4d；先算 `h` 再 ReLU，别把 ReLU 写到第二层后面。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def ffn(x, W1, b1, W2, b2):
    return F.relu(x @ W1 + b1) @ W2 + b2
```

## BCE（二元交叉熵损失）

`中等` ｜ **思路**：从 logits 直接算，用 `max(z,0) − z·y + log1p(exp(−|z|))` 的稳定形式。

```python
def bce(logits, targets):
    z = np.asarray(logits, float); y = np.asarray(targets, float)
    # log(1+e^-|z|) + max(z,0) - z*y，数值稳定形式
    return (np.maximum(z, 0) - z * y + np.log1p(np.exp(-np.abs(z)))).mean()
```

**复杂度**：O(n)

**易错**：先 sigmoid 再取 log 会在饱和区丢精度甚至出 `log(0)`。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def bce(logits, targets):
    return F.binary_cross_entropy_with_logits(logits, targets)   # 不要用 binary_cross_entropy
```

**torch 侧注意**：用 `binary_cross_entropy_with_logits` 而不是 `binary_cross_entropy`，后者要求你先 sigmoid，数值更差。

**原理**：[交叉熵（二分类特例）](../../06-post-training/distill/01-entropy-ce-kl-jsd.md)

## Max Pooling（二维最大池化前向传播）

`中等` ｜ **思路**：滑窗取 max。

```python
def max_pool2d(x, k, stride=None):
    x = np.asarray(x, float); stride = stride or k
    N, C, H, W = x.shape
    Ho, Wo = (H - k) // stride + 1, (W - k) // stride + 1
    out = np.empty((N, C, Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            out[:, :, i, j] = x[:, :, i*stride:i*stride+k, j*stride:j*stride+k].max((2, 3))
    return out
```

**复杂度**：O(N·C·Ho·Wo·k²)

**易错**：stride 默认等于 k（不重叠）；反向传播时梯度只回传给最大值那个位置。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def max_pool2d(x, k, stride=None):
    return F.max_pool2d(x, k, stride=stride or k)
```

## KL 散度

`中等` ｜ **思路**：`sum(p·(log p − log q))`。

```python
def kl_div(p, q, eps=1e-12):
    p = np.asarray(p, float); q = np.asarray(q, float)
    return float((p * (np.log(p + eps) - np.log(q + eps))).sum(-1).mean())
```

**复杂度**：O(n)

**易错**：**方向不能反**，KL(p‖q) 期望在 p 下；加 eps 防 `log(0)`；结果非负但不对称。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
def kl_div(p, q):
    # F.kl_div 的第一个参数要 log-prob，且方向是 KL(target || input)
    return F.kl_div(q.log(), p, reduction="batchmean")
```

**torch 侧注意**：`F.kl_div` 的坑最多：第一个参数要 **log-prob**，而且方向是 `KL(target ‖ input)`，和数学写法反着；`reduction` 要用 `batchmean` 不是默认的 `mean`。

**原理**：[KL 散度 / forward vs reverse](../../06-post-training/rl/07-kl.md)

## SGD 随机梯度下降

`中等` ｜ **思路**：`p ← p − lr·g`，可选动量和 weight decay。

```python
class SGD:
    def __init__(self, lr=0.01, momentum=0.0, weight_decay=0.0):
        self.lr, self.mu, self.wd = lr, momentum, weight_decay
        self.v = None
    def step(self, params, grads):
        p = np.asarray(params, float); g = np.asarray(grads, float)
        if self.wd: g = g + self.wd * p
        if self.mu:
            self.v = g if self.v is None else self.mu * self.v + g
            g = self.v
        return p - self.lr * g
```

**复杂度**：O(d)

**易错**：动量是 `v ← μv + g` 然后用 v 更新；weight decay 加在梯度上（AdamW 则是直接从参数里减）。

**PyTorch 版**（与上面 NumPy 版逐个对拍，数值一致）

```python
class SGD:
    """等价于 torch.optim.SGD(params, lr, momentum, weight_decay)。"""
    def __init__(self, lr=0.01, momentum=0.0, weight_decay=0.0):
        self.lr, self.mu, self.wd = lr, momentum, weight_decay
        self.v = None
    def step(self, p, g):
        if self.wd: g = g + self.wd * p
        if self.mu:
            self.v = g.clone() if self.v is None else self.mu * self.v + g
            g = self.v
        return p - self.lr * g
```

**torch 侧注意**：`torch.optim.SGD` 的 momentum 实现就是这个式子；注意 `weight_decay` 是加在梯度上。

**原理**：[SGD 与梯度累积](../../03-training-fundamentals/03-gradient-accumulation.md)
