## 几条贯穿多题的模板

**滑动窗口**（3、76）：右指针无脑扩，条件满足后收缩左指针，左边界只右移不回退。

**二分边界**（34、33、300）：统一写 `lower_bound` 语义（第一个 `>= x`），循环用 `lo < hi`、`hi = mid` / `lo = mid + 1`，不写 `mid ± 1` 的混合形式就不会死循环。

**链表哨兵**（21、19、23、25）：`ListNode dummy(0, head)`，头节点可能被删/被换时必须用，能省掉所有特判。

**BFS 分层**（102、103、199）：进循环第一件事 `int sz = q.size()`，本层节点数固定住。

**回溯**（46、22）：
```text
backtrack(状态):
    if 终止: 收集答案; return
    for 选择 in 选择列表:
        做选择; backtrack(); 撤销选择
```

**DP 下标偏移**（1143、72、139）：`dp[i][j]` 表示前 i / 前 j 个字符，字符要用 `a[i-1]`、`b[j-1]`，边界行列单独初始化。

**股票统一式**（121、122、123、188）：状态是 `dp[i][k][0/1]`，滚动后就是 `buy[j] / sell[j]`，`buy[j]` 依赖 `sell[j-1]`。121 是 k=1、122 是 k=∞、123 是 k=2、188 是一般 k。
